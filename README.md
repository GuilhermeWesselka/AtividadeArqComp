# 🧩 Palavras Cruzadas: Arquitetura de Computadores

Um jogo de palavras cruzadas online criado especialmente para ajudar os colegas de sala a revisarem o conteúdo de **Arquitetura de Computadores** de um jeito mais leve e dinâmico antes das provas.

## 💡 Sobre o Projeto

A ideia do site é transformar o estudo teórico em um desafio prático. Em vez de apenas reler slides e anotações, você testa seus conhecimentos na prática tentando adivinhar os termos a partir das suas definições e funções no sistema.

## 📚 Temas Abordados

Sem spoilers das respostas por aqui, mas prepare-se para revisar conceitos essenciais sobre:
* **Processamento:** Os componentes principais que fazem os cálculos e controlam as operações.
* **Memórias:** Diferentes tipos de armazenamento, desde os mais rápidos e temporários até os permanentes.
* **Comunicação Interna:** Como os dados e endereços trafegam entre os componentes do computador.
